# SWEETS タブ用の写真フォルダ

ここに写真（.jpg / .jpeg / .png）を入れてコミットすると、
トップページの **SWEETS** タブに自動で表示されます。

- `photos.js` を編集する必要はありません
- 大きいサイズのままアップしてOK（自動で長辺1800pxに縮小されます）
- 並び順はファイル名の昇順。順番を決めたいときは `01_xxx.jpg` のように番号を付けてください
- 反映まで1〜3分ほどかかります（GitHubの Actions タブで進行状況が見られます）

このREADME.mdは消さないでください（フォルダを保持するために必要です）。
